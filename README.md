# Genshin Artifact Generator

Genshin has an artifact system that heavily depends on luck. This program serves as a means to simulate how long it will take to get your desired artifact. Each artifact will automatically be 5 stars and start with 4 substats. The user will input either y or n when asked to make or upgrade an artifact. When upgrading an artifact, the user can input any positive integer to upgrade it and any integer from 0 below to cancel upgrading. The rates of artifacts are as follows:

### [Artifact Distribution](https://genshin-impact.fandom.com/wiki/Artifact/Distribution)

Artifact types all have an equal chance of appearing. The random main stat gained will be based on the artifact type. All substats have an equal chance of appearing, but they must each be unique stats.

### [Artifact Scaling](https://genshin-impact.fandom.com/wiki/Artifact/Scaling)

The main stat will have a linear growth based on the artifact level. Each artifact level up will always upgrade the main stat.

### [Artifact Stats](https://genshin-impact.fandom.com/wiki/Artifact/Stats)

The substat will be upgraded every 4 artifact levels. All current substats have an equal chance of getting upgraded. The upgraded substat will have an equal chance of rolling to 70%/80%/90%/100% of the maximum value of the substat.
